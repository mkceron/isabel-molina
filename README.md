# Isabel Molina — Portfolio Website

Static GitHub Pages-ready rebuild using the original Spanish biography and original media recovered from the supplied WordPress backup.

## Structure
- `index.html` — single-page portfolio
- `assets/css/styles.css` — responsive styling
- `assets/js/main.js` — mobile navigation/year
- `assets/images/` — curated original portfolio photographs
- `.nojekyll` — tells GitHub Pages to serve the site as-is

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.

## Before publishing
Replace the placeholder contact note in `index.html` with Isabel's current professional email, phone/WhatsApp, representation and social links.
